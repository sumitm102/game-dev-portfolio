# Sumit Mandal — Game Development Portfolio

A lightweight static portfolio designed to showcase Unity/game-development work for technical internship applications.

## Preview
Open `index.html` in any browser.

## Before sending it to anyone
1. Replace `YOUR_EMAIL`, `YOUR_GITHUB`, and `YOUR_LINKEDIN` in `index.html`.
2. Add screenshots or GIFs for the 3D stealth game and 2D RPG.
3. Replace the Game Jam placeholder with the actual finished game once applicable.
4. Add GitHub / playable-build buttons to individual projects where available.
5. Verify every project description and metric before publishing.

## Publishing
This is a static site, so it can be hosted with GitHub Pages, Netlify, or Vercel without a backend.

## Suggested media
For each featured game, use:
- 1 strong 16:9 hero screenshot
- 1 short gameplay GIF or video
- 2–3 supporting screenshots
- GitHub repository and/or playable build link
